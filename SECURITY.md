# Security policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue or discussion.
Use the repository's **Security → Report a vulnerability** flow to submit a
private report to the maintainers. Include reproduction details, affected
versions, impact, and any suggested mitigation, but do not include real user
credentials or private datasets.

The maintainers will acknowledge the report, validate the impact, coordinate a
fix, and disclose it only after affected releases can be updated.

## Supported versions

Until the first public release, only the current `main` branch is supported.
Published support windows will be added when signed release distribution is in
place.
